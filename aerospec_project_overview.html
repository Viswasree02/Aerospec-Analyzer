01 / THE PROBLEM BEFORE THE SOLVER

Small gaps in a request become expensive downstream.

A simulation can only be as actionable as its inputs. Aerospec puts a review step between design intent and solver setup.

A

Open-ended language

Words such as “adequate,” “smooth,” or “optimal” leave acceptance criteria open to interpretation.

B

Unspecified conditions

Boundary physics, operating state, and measurable targets may be missing when the request reaches the analyst.

C

Late clarification

Questions raised during meshing or solver setup can trigger avoidable handoffs, rework, and delays.

Review point:make uncertainty visible while the engineer can still resolve it in the work request.

02 / THE REVIEW WORKFLOW

One request moves through four clear stages.

The workflow pairs quick, repeatable checks with an engineering-focused AI review and a local record of the outcome.

03 / DETERMINISTIC PRE-CHECK

Catch common input issues without an AI call.

The deterministic layer is quick, consistent, and available even when Gemini is not configured.

Value recognitionExamples
30,000 ft→one value + unit
Mach 0.78→dimensionless
M = 0.82→dimensionless
Re = 1.2e6→dimensionless
allowable deflection 2.5→unit needed

What the pre-check measures

Vague-term signals+15 each
Numbers missing units+10 each
No imperative language+10

Signals are capped and combined into a bounded ambiguity index. “Shall,” “must,” and “required to” count as imperative language.

Index: 5–95%

06 / DATA FLOW & ENGINEERING BOUNDARIES

A review aid with clear data and sign-off boundaries.

Aerospec helps make a work request more actionable; it does not replace approved engineering procedures.

SpecificationText + selected metadata
→

Audit recordLocal SQLite history

Data handling

When AI review runs, the specification text and selected metadata are sent to Google Gemini. Audit records are stored in the project’s local SQLite database.

Credential & access

The AI key is read from the GEMINI_API_KEY environment secret. Live model access depends on the configured key, account, and model availability.

Engineering review remains the authority for simulation sign-off.
